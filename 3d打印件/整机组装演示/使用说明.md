# 机械臂与摄像头：整机组装演示

本页用于看懂“原机械臂怎样组成整机、新增摄像头支架放在哪里”。它是离线教学演示，不连接开发板，也不会驱动舵机。

## 怎么看

1. 双击同目录的 `组装演示.html`，用 Edge、Chrome 或其他支持 MP4 的浏览器打开。
2. 点击“播放动画”。动画不会自动播放。可以拖动进度条、暂停，或改为 `0.5×` 慢速。
3. 右侧“想看哪一步？”可跳到对应章节；点击章节会先暂停，便于看清细节。
4. 下方四个视角可以分别查看整机、爆炸视图、侧面、摄像头细节。“放大原图”会打开完整图片。
5. 不想看运动时，切换“看静态步骤”。如果系统开启“减少动态效果”，网页会默认打开静态步骤。

键盘支持：

- `Tab` / `Shift+Tab`：移动焦点；`Enter`：使用按钮或链接。
- 焦点不在控件内时：空格播放或暂停，左右方向键前后移动 1 秒，`Home` 回到开头，`End` 到末尾，`F` 全屏。
- 四个视角按钮之间可以用方向键切换，`Home` / `End` 切到首尾。
- 焦点在视频自带控件、速度菜单、进度条内时，优先使用控件本身的键盘行为。

## 什么是真实模型，什么是示意

- 塑料结构来自本地机械臂 STL 和新增支架模型。
- 舵机、开发板、镜头与线材为展示结构关系的代理模型，不是厂家精确 CAD。
- 用户使用的开发板为 XIAO ESP32S3 Sense；模型中的叠板厚度、镜头位置、连接位置和排线方向仍需依据实物测量复核。
- 动画是帮助理解连接关系的教学顺序，不是机械臂可以执行的轨迹，也不是经过工艺验证的装配作业指导书。
- 爆炸图为了看清零件而刻意把部件拉开，不能用这些间距指导打印或接线。

## 不要把渲染当成实物验证

该演示不代表已经完成：实体打印、卡扣/夹口试装、螺丝适配、舵机零位标定、布线、镜头视野验证或全行程碰撞测试。

原有四路舵机接线方案不因本次可视化改变。不得仅凭示意线材图直接接线。首次上电前，仍须依照已确认的电气接线文档逐项检查。

## 维护时间线

HTML 内的 `CHAPTERS` 数组集中保存章节起点、标题、说明和对应静态图编号。起点单位为秒，必须与实际渲染动画一致；以最终 `assembly_manifest.json` 的动画记录为准。静态图编号由 `VIEWS` 数组决定。

本版动画长 24 秒，24 fps，共 576 帧：

| 起点 | 观看内容 |
| --- | --- |
| 00:00 | 零件展开，先看总体组成 |
| 00:02 | 底座与电子舱 |
| 00:05 | 回转座与大臂 |
| 00:09 | 小臂与夹爪 |
| 00:13 | 摄像头支架与组件 |
| 00:17 | 拼好后绕机观察 |

颜色只用于识别：原底座与大臂为橙色，小臂浅灰白，新增摄像头支架青绿色，舵机炭黑色，PCB 绿色。它们不是电气接线颜色。

## 原模型来源与署名

原机械臂设计为 **RACBOTS** 的「Brazo Robótico - Robotic Arm」；本地使用的是 **Arun Kumar** 的带元件底座改版 [Robotic Arm with a base for components](https://www.printables.com/model/1596575-robotic-arm-with-a-base-for-components)。本地原始 PDF 注明 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 许可。本装配场景中的衍生网格继续按同一许可提供。改动包括舵盘槽试配版本、新增摄像头支架、模型重定位、颜色和装配动画；示意电子器件为本地生成。分享衍生模型时应保留署名、许可和改动说明。

## 在 Blender 里自己看

打开 `robot_arm_camera_assembly.blend`，时间轴停在第 432 帧（已经拼好）。切到相机视图可看当前取景；普通三维视图可绕模型旋转。

- 第 1 帧：零件展开。
- 第 108 帧：底座与电子舱合拢。
- 第 204 帧：回转座与大臂合拢。
- 第 305 帧：小臂与夹爪合拢。
- 第 408 帧：摄像头和支架合拢。
- 第 432—576 帧：相机绕整机观察，机械臂保持同一姿态。

在时间轴点击播放即可看关键帧动画。对象按 01—10 组命名；示意硬件对象带有 `is_visual_proxy` 属性，不应导出为打印件。`tapa-v2.stl` 与 `base-2.stl` 是替代造型，本场景只使用后者。夹爪采用上下两层齿轮关系：下层小轮驱动与一片夹爪同轴的大轮，上层两夹爪相互啮合；齿相位和螺丝深度仍需实物确认。

## 重现与检查

`build_assembly.py` 用原 STL 生成场景、四张静态效果图和装配记录；`encode_animation.py` 将 576 张帧图编码为带中文步骤标题的 MP4。静态图用 Blender Eevee，视频用 Workbench 以保证步骤清晰。模型以毫米定义，整体按 0.001 缩放到 Blender 的米制场景。

```powershell
& 'D:\blender\blender.exe' -b --python-exit-code 1 --python '.\build_assembly.py'
& 'D:\blender\blender.exe' -b '.\robot_arm_camera_assembly.blend' -s 1 -e 576 -a
python '.\encode_animation.py'
```

在本文件夹运行上述命令。重新生成会覆盖本文件夹内的场景/效果图/视频；需要保留手工调整时，先把 `.blend` 另存为新名称。不会覆盖原始 STL。
