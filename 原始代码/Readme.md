## 已知问题

- 夹爪开机角度从 `0°` 开始，可能先撞到机械限位，再移动到打开位置。
- 所有关节允许 `0–180°`，没有针对打印结构的安全软限位。
- 网页以 50 ms 节流发送滑块数据，停止拖动时的最后一个角度可能没有发出。
- 页面不读取设备状态，刷新后显示值可能与机械臂当前目标不一致。
- 第一次调节任意滑块会同时发送页面中另外几个默认角度，可能引起意外移动。
- Reset 请求可能受到同一个 50 ms 节流限制而被忽略。
- 页面不显示请求失败、设备断线、当前角度或目标角度。
